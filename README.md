# CBSE-School-in-Kukatpally-Tatva-Global-School-Hyderabad
Tatva Global School offers CBSE-affiliated K–12 education from Nursery through Grade 12 in Kukatpally, Hyderabad.
Its academic programme follows CBSE standards and NCF-aligned learning outcomes.
The school combines classroom learning with sports, clubs and experiential activities.
